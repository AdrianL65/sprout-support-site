# sprout-support-site

Home and help pages for **Sprout**, served by GitHub Pages at
**https://sprout-support.mikrodev.net**.

| Path | What |
|---|---|
| `/` | Sprout home |
| `/faq/` | Help and contact |

Policies: https://sprout-legal.mikrodev.net · Contact: support-sprout@mikrodev.net

Plain HTML and CSS with no build step. Preview locally with
`python3 -m http.server 8000`, then open http://localhost:8000.
